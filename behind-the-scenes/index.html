Detrás del
proceso creativo.

Una mirada al trabajo que ocurre antes de publicar una web: referencias, estructura, decisiones visuales, pruebas y pequeños detalles. No todo empieza perfecto; cada proyecto se construye explorando y afinando.

01 / ESTRUCTURA Y EXPERIENCIA

Organizar antes de diseñar

Antes de elegir colores o tipografías, ordeno la información. Qué necesita encontrar una persona, qué debe entender primero y cuál es el camino más sencillo para contactar con el negocio.

02 / TIPOGRAFÍA

El tono también se diseña

Una combinación tipográfica puede hacer que una marca se sienta cercana, sobria o contemporánea. Busco que los títulos tengan personalidad y que los textos sean cómodos de leer.

03 / DIRECCIÓN VISUAL

Menos elementos, mejores decisiones

Exploro paletas, espacios y proporciones para que cada elemento tenga una razón de estar. La intención es que el diseño acompañe al contenido, no que compita con él.

PALETA DE EXPLORACIÓN

Calma y claridad

Una base neutra permite que el contenido respire. Un tono cálido aporta carácter sin distraer.

REVISIÓN RESPONSIVE

De escritorio a móvil

04 / ADAPTACIÓN

Diseñar para cada pantalla

La web debe conservar su claridad en móvil, tablet y ordenador. Reviso tamaños, espacios y orden de los contenidos para que la experiencia siga siendo sencilla.
